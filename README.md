Production-grade full-stack fintech & AI engine providing:
- High-throughput checkout & order orchestration with Redis idempotency
- Double-entry immutable accounting ledger with strict debit/credit balance proofs
- HMAC-SHA256 verified webhook ingestion with BullMQ async processing & DLQ
- Chaos engineering simulator (duplicate webhooks, transient 500s, latency injection)
- Gemini-powered AI reconciliation, automated chargeback rebuttal generation, and smart decline recovery
- Crisp white-and-royal-blue fintech dashboard built with React, Vite, Tailwind CSS, and Framer Motion
